# routecheck v0.2 (AS-path sets reaching AS-ANY) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move routecheck to rpsl v0.30.0, where an as-set reaching AS-ANY in an AS-path regexp is any AS, and name such a set in the verdict that accepted a route.

**Architecture:** pathre already matches through `ASNSet.Has`; the test oracle and the vectors reader learn `Any()`; `verdict.Compile` records, per conjunct, the any-sets its AS-path tests name, and `Decide` copies the accepting conjunct's into `Verdict.AnySets`; the CLI prints them. R19/R21 remain for filter position.

**Tech Stack:** Go 1.23 module `github.com/rkolesnichenko/routecheck`; rpsl v0.30.0; mrt v0.1.0.

**Spec:** docs/superpowers/specs/2026-10-18-v0.2-any-set-design.md

## Global Constraints

- go.mod requires exactly `github.com/rkolesnichenko/rpsl`, `/types`, `/resolve` at `v0.30.0` (ast, lexer indirect at v0.30.0) and `github.com/rkolesnichenko/mrt v0.1.0`; no `replace`, no go.work.
- Never commit machine-local paths (home-directory or `/private` paths); the repo is public.
- `scripts/check.sh` must pass after every task (run with `GOMAXPROCS=4`); real-data runs and benchmarks only under the memory guard, one at a time, at normal priority (`MEMGUARD_NORMAL_PRIORITY=1`), never beside check.sh.
- API changes are reviewed through `api/*.txt` (`ROUTECHECK_API_UPDATE=1 go run ./internal/apisurface -check` rewrites them).
- Goldens change only by `ROUTECHECK_GOLDEN_UPDATE=1 go test ./internal/cli`, and the diff is read.
- Every figure written into a doc comes from a command run on this branch, with its log under `.data/`.

## Review Focus

1. A clause with two conjuncts, only one naming an any-set, where the route is accepted by the other: `AnySets` must be nil (per conjunct, not per clause). → Task 3, `TestDecideAnySetsPerConjunct`.
2. A negated any-set test (`NOT <AS-ALL>`) in the accepting conjunct, route with an empty path: accepted, `AnySets` names the set (either polarity counts). → Task 3, same test.
3. Rejected and Undecided verdicts never carry `AnySets`, even when a clause names an any-set. → Task 3.
4. A vectors file whose header has no `version` or version 1 is refused, not read with any-sets as absent. → Task 2, `TestVectorsHeaderVersion`.
5. A set name written in another case (`as-all`) is the same any-set for the oracle and for pathre. → Task 2, reoracle generator already lowers names (`gen.go:185`); the differential test covers it once `AS-ALL` is drawn — assert a floor.
